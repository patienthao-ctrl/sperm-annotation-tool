# 0006 自动预标与按目标审查

- 日期：2026-11-12
- 状态：采用（部分取代 0003：审查单位由“帧”改为“目标”；0003 的“不做自动疑点判定、发现错误直接改”保留）

> 要点
> - 标注：打开视频由检测器逐帧预标并连成目标轨迹；标注员只在几张查漏帧上补漏，点一下补整条。首尾帧 + SAM3 追踪不再是主流程。
> - 审查：一个目标（整条轨迹）一张卡片，回答“这是精子吗？”：有尾巴 / 没尾巴 / 不是（整条删除）/ 看不清。答案绑定轨迹内容，改动后重新问。
> - 通过：全部目标已答、查漏帧都看过、快速浏览过全片、没有标注的帧确认无目标。导出门槛不变。
> - 导出：有尾、无尾都是“精子”一类；“看不清”导出为忽略区域；有尾/无尾写入清单属性。

## 背景

第一批数据训出的检测器 `yolo26s-sperm264-head-v6`（金标 F1 0.952，接近人工上限 0.966）随仓库替换了 `head-detector.pt`。对 264 段已审查标签的审计发现，主要问题不在中间帧，而在“人画首尾帧 + 追踪”本身：首尾帧漏标一个，整条轨迹都漏；人工框松紧不一（约 40% 的框是头的 2.7 倍）并随追踪传下去；中间帧几何并不比人工首尾帧差（F1 0.921 对 0.928）。一段 2K 视频（rec_20261019_9）的标签只有约一半的头。

逐帧检测会闪烁：第 n 帧检出、第 n+1 帧漏掉。实验表明“高分起轨、低分只延续、断 ≤3 帧插值”可以补齐：基线轨迹内 24 处断帧降为 0，标签召回 0.964 → 0.993；补出的框没有落在空白处，拿不准的集中在少数目标上，适合按目标复核。

逐帧确认（0003）要求审查员每帧都点一次，目标多、帧多时工作量大，且同一目标在几十帧里反复被看；而判断“是不是精子”本来就是按目标做的。团队要求工具零学习、少文字，同时不能删掉现有功能。

## 决定

1. **自动预标**（`detector_tracks.py`、`POST /api/prelabel/{id}`）：整帧长边 1024 推理（与训练一致），阈值 `HEAD_DETECTOR_CONF`=0.30、`HEAD_DETECTOR_LOW_CONF`=0.10；门限 100 px@4K，速度取最近 3 步，低分框可隔最多 3 帧延续，没有检测的帧不补框（2026-11-12 改：插值框在目标出画、快速跳动时落在空背景上），至少 2 帧高分；交会、跳变、中途出现、低分多的轨迹打标记。只判断“是不是同一个”，不用运动判断“是不是精子”。不需要 SAM3。
2. **查漏帧**：每 10 帧一张、末帧，加轨迹中途起止帧（附近 2 帧内已有则不加）。标注员在这些帧看全图补漏，逐张记录“看完了”（`annotation_frame_scans`）。闪烁由程序补，人只找模型从头到尾没报的目标。
3. **补漏**：点一下，服务端在缓存的检测里沿位置找同一个头（只用没被占用的框），一次加到所有找到的帧（只用真实检测，不估算），一次撤销。找不到再手动画框。
4. **按目标审查**（`evidence_policy=target-review-v1`）：首轮列全部目标，重审只列与上次通过相比轨迹有变化的目标，审查中途新出现的目标（拆分、补框）也列入。答案存轨迹摘要；“不是”之后页面整条删除，未删除不能通过。可能连错的目标先问“这几张是同一个精子吗？”，不是则在换人的那一帧拆开。混入一张不标注的复判卡片记录一致率，不计入通过。
5. **通过条件**：上述目标全部答过且未再改动；预标视频的查漏帧全部看过；快速浏览一遍全片（播到最后一帧才记录）；没有任何标注的帧确认无目标。`require_passed` 不变。
6. **增强**：一个按钮，服务端按训练复核图的方法（中值背景相减、增益 8）生成，不再提供亮度/对比/反相调节。
7. **旧数据**：已审查或已有 SAM3 结果的视频保持原样，页面提供“用新模型重新预标”（清空标注后重新预标，审查失效）。进行中的旧轮次（逐帧或更早的清单）读取时归档并改建为目标清单；已通过的旧轮次仍是有效通过记录。

## 放弃的方案及原因

- **保留首尾帧 + SAM3 作为主流程，只换检测器**：漏标传播和松框正是来自这一流程。
- **用 ultralytics 自带 ByteTrack 连轨迹**：默认配置下断帧反而增多（62 处）、召回降到 0.921。
- **让模型直接判定、自动删除“模型不认”的标签**：复核显示模型不认的标签约一半是对的，模型认可的也有约 7% 错。模型只用来排序和提候选。
- **审查继续逐帧确认，目标卡片只做辅助**：工作量和重复劳动不变；整段浏览一遍加按目标回答已覆盖“有没有明显漏掉”。
- **导出三类（有尾/无尾/看不清）**：检测器只有一类，判尾准确率不够；看不清既不是正样本也不是背景，用忽略区域表达。
- **用户可调的增强参数**：训练复核已验证一种增强最有效，调节只会增加学习成本。
