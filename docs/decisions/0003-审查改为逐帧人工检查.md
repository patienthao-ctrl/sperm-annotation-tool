# 0003 审查改为逐帧人工检查，去掉自动找异常

- 日期：2026-11-03
- 状态：部分被 [0006](0006-自动预标与按目标审查.md) 取代（审查单位由逐帧确认改为按目标判定；“不做自动疑点判定、发现错误直接改”仍有效）。原取代 [0002](0002-审查按对象轨迹与追踪框几何.md) 的第一、二、三部分

## 背景

审查清单原先由系统挑出“最可能出错”的帧：追踪疑点（可能漏标/跟错/偏离/静止）、框几何异常、出画尾帧、计数突变、整帧查漏、随机抽检、修正后复查，另有“不是精子”排除记录和训练包里的位置判断。追踪阶段为此每 5 帧做一次全图检测、挑疑难片段做反向核验。0002 又加了改帧联动和按对象检查视图。

实际使用中，审查员仍然逐帧看完全片才放心通过；自动疑点漏掉的问题（框被杂质撑大、出画残留）也只能靠逐帧发现。清单规则、阈值和联动操作越来越多，审查员要理解每类提示，开发和测试的维护量也很大。团队讨论后一致决定简化：标注首尾帧 → AI 追踪 → 审查员逐帧检查。

## 决定

- 审查清单就是帧：首轮是视频全部帧；通过后再改动，重新审查只列内容变化的帧。审查员看一帧、有错直接改、确认这一帧（无标注的帧确认无目标），全部确认后显式“审查通过”。
- 删除所有自动找异常的逻辑：疑点分类与证据聚合、框几何疑点、出画尾帧、计数突变、整帧查漏、随机抽检、修正后复查、“不是精子”排除、采用反向轨迹/候选补框、画面上的候选圆圈与强调。
- 删除改帧联动（尺寸应用到相邻帧、删到轨迹结束、向前/向后补框、差异提示、撤销联动）和按对象检查缩略图（含 `/api/track/object-crops`）。
- 追踪阶段不再为审查做每 5 帧全图检测和疑难片段反向核验；追踪自身用的身份证据（出画保护）、端点核验和三路综合不变，0002 第四部分的尺寸约束候选 S 保留。
- 训练包不再生成 `review/decisions.jsonl`；`reviewEdited` 保留（来自通过轮次的修改记录）。

## 放弃的方案及原因

- **保留自动疑点作为辅助提示**：逐帧检查后提示是重复信息，还要维护阈值和测试；审查员容易只看提示、不看整帧。
- **保留联动编辑作为改框工具**：用户决定一并去掉，审查员逐帧修改即可；需要时可以再按新需求设计。
- **重新审查也查全部帧**：沿用“重新审查只查改动部分”，未改动的帧上次已经人工确认过。

## 影响

- 代码：`backend/app/annotation_review.py`（帧清单、按帧确认、旧清单改建、通过时固定无目标帧 `empty_frames_json`）、`annotation_review_routes.py`（`PUT /media/{id}/frames/{frameIndex}` 取代 `/items/{itemId}`）、`review_evidence.py` 与 `tracker.py`（去掉检测抽样和反向核验）、`training_export.py`、`main.py`（删除缩略图接口）；前端审查面板、审查 store/API、`AnnotatePage.vue`，删除联动编辑与审查定位相关文件。
- 数据：进行中的旧清单下次读取时改建为帧清单，旧项与检查记录归档到 `checklist_history_json`；已通过轮次不改写，其“确认无目标”仍有效；`annotation_review_exclusions` 只读保留。
- 文档：WORKFLOW 审查章节、ANNOTATION、API、STORAGE_LAYOUT、用户使用说明、测试说明。
